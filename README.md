# University of Sydney Union Website

Welcome to the **University of Sydney Union** website! This site is built using **HTML**, **CSS**, **Bootstrap 4**, a custom CSS file for styling, 
and **basic JavaScript** for interactive features like navbar appearance and search bar functionality. It is optimized for both mobile and tablet views with the use of media queries.

🌍 **Live Site:** [University of Sydney Union Website](#)(https://tanvirapon.github.io/Project-USU/)

## 🛠 Technologies Used
- **HTML5** – Structuring the webpage.
- **CSS3** – Styling and layout design.
- **Bootstrap 4** – For responsive design and components.
- **Custom CSS** – For additional styling in the `style.css` file.
- **JavaScript** – For navbar appearance and search bar click functionality.
- **Fonts** – Custom font files added for unique typography.

## 📌 What I Learned
- How to build a **fully responsive website** using **HTML**, **CSS**, **Bootstrap 4**, and **JavaScript**.
- **Mobile-first design** practices with the use of media queries.
- Structuring a webpage for both **tablet** and **mobile** devices.
- Integrating **custom fonts** and **extra styling** using the `style.css` file.
- Adding basic **JavaScript functionality** for navbar and search bar interactions.

- Modify the content in index.html to update the webpage.
- Customize styles by editing the style.css file.
- Adjust the media queries in style.css for tablet and mobile responsiveness.
- Add any JavaScript interactions in script.js.

## 📱 Mobile & Tablet Responsive

- Special media queries for tablet views to ensure proper layout.
